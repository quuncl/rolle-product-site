# Задача для Codex: ROLLÉ 3D Product Experience

Ты работаешь над существующим интерактивным сайтом для персонального роллера брендирования упаковки. **Продолжай готовый код**, не заменяй работающий интерфейс пустыми макетами.

## Исходные материалы

- `README.md` — запуск, работающие функции и ограничения.
- `PROJECT_BRIEF.md` — полный сценарий лендинга и roadmap.
- `index.html`, `assets/styles.css`, `assets/app.js` — реализованный MVP.

## Цель

Превратить MVP в production-ready премиальную e-commerce презентацию устройства ROLLÉ со скролл-анимациями, точной 3D-моделью, реалистичной демонстрацией печати, конструктором клише и заказом. По умолчанию русский язык, мобильная версия обязательна. Тёмный графит + светлая бумага + коралловый акцент.

## Правила реализации

1. Проверяй, что проект запускается, 3D работает и все элементы управления кликабельны.
2. Сохраняй доступность: keyboard navigation, aria, reduced motion, контраст, touch interactions.
3. Указывай честно, что это 3D-концепт до получения реальной CAD-модели и результатов испытаний.
4. Не утверждай, что продукт уже доступен, сертифицирован, проверен, имеет фиксированную цену или гарантированный цвет печати.
5. Не подключай платежи, формы передачи данных, аналитику или пользовательские аккаунты без явного задания и конфигурации backend.
6. Любые загруженные изображения должны валидироваться по MIME и размеру. Не отправляй файлы третьим лицам без согласия.
7. По возможности используй реальную модель glTF/GLB на базе замеров; до этого не выдавай процедурную WebGL-модель за точную инженерную копию.
8. Пиши понятный код с разделением 3D-сцены, логики конструктора и UI.

## Ближайшие задачи

- [ ] Заменить procedural 3D на реальный оптимизированный `.glb` после получения CAD/Blender-модели.
- [ ] Добиться реалистичного контакта роллера с коробкой: texture painting на UV / dynamic canvas texture + правдоподобная анимация вращения.
- [ ] Связать оформление заказа с backend, платежной системой и учётом производственных макетов.
- [ ] Добавить валидацию SVG/растровых изображений, ограничения печати (min stroke, printable area), vector preview.
- [ ] Улучшить performance: IntersectionObserver, адаптивное DPR, fallback для WebGL1/без WebGL, lazy loading.
- [ ] Тесты на mobile Safari, Chromium, Firefox; Lighthouse, accessibility audit.
- [ ] Создать production SEO/OG assets, privacy/terms, analytics only with consent.
