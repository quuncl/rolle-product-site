# Логокат — интерактивный 3D-сайт для роллера брендирования упаковки

Готовый автономный MVP премиального продуктового сайта на русском языке. На первом экране и в разделе устройства используется **GLB-сборка из предоставленного архива `index.zip`**. Three.js и загрузчик находятся локально, сторонние CDN не используются. Можно развернуть как статический сайт. Основные секции уже сверстаны.

## Быстрый запуск

```bash
cd rolle-3d-site
python3 -m http.server 5173
```

Откройте http://localhost:5173. Для загрузки GLB и ES-модулей нужен HTTP-сервер: открытие `index.html` через `file://` не поддерживается.

## Что работает

- 3D-модель в разделе «Устройство роллера» со студийным окружением, разными материалами пластика, резины и металла, микрофактурой поверхности и тенями между деталями. Вращение мышью/тачем и медленная автоподстройка.
- Вращение печатного колеса вокруг оси, отдельное от управления ракурсом.
- До первого 3D-кадра показан нейтральный индикатор загрузки; изображение роллера используется только при ошибке 3D или без JavaScript. При загрузке не происходит подмены фотографии моделью.
- Демонстрация печати в 3D на первом экране. Когда коробка появляется в области просмотра, запускается показ в трёх цветах. Для каждого цвета роллер проходит по крышке, затем по передней грани. Камера приближает колесо и показывает оба готовых оттиска. Нажатие на сцену приостанавливает или возобновляет показ.
- Конструктор: текст бренда, PNG/JPEG/SVG логотип, цвет оттиска, 3 вида основы, интервал повторения, примеры надписей, перемещение полосы мышью/касанием/стрелками и анимация прокатки.
- Скачивание SVG-превью.
- До/после с интерактивным ползунком и синхронизацией материала, надписи, цвета и положения оттиска с конструктором.
- Приглашение в конструктор через 5 секунд видимого просмотра; показывается один раз за сессию вкладки.
- Плавный FAQ, адаптивная навигация, локальное скачивание заявки в TXT с проверкой необязательных полей имени, email или телефона. Данные не отправляются на сервер.
- Адаптивность для смартфонов, отсутствие внешней телеметрии, базовая поддержка reduced motion.

Изображения коробок созданы с помощью ImageGen и являются визуализациями, а не фотографиями результатов испытаний.

В демонстрации на барабан добавлена небольшая визуальная метка вращения. Материал коробки использует текстуру из существующего изображения крафта. Фактура пигмента — художественная визуализация; она не предсказывает качество реального оттиска.

## Важно перед коммерческим запуском

Это концепт, не модель изготовленного и проверенного изделия. 3D-сборка взята из `index.zip` → `assets/roller.glb`, источник в метаданных — «Сборка роллера 06». Восемь деталей, около 1,9 МБ, единицы — метры, вертикальная ось Y; геометрия сохранена без изменений. Соответствие размеров реальному изделию и результаты испытаний не подтверждены. Требуются проверка размеров, фото реальных оттисков и тесты совместимости маркеров/клише. Реальные корзина, цена, оплата, CRM, backend, безопасность загрузок и политика персональных данных **не реализованы**. SVG из конструктора является визуальным эскизом, не готовым файлом для изготовления печатного клише.

## Структура

- `index.html` — вся семантическая разметка и тексты.
- `assets/styles.css` — адаптивный дизайн, анимации и CSS-сцены.
- `assets/app.js` — интерфейс, скролл-презентация и конструктор.
- `assets/roller-viewer.js` — GLB-сцены: мышь/касание, стрелки и Home, выбор цвета, reduced motion, загрузка по видимости, резервные изображения.
- `assets/roller-appearance.js` — сглаживание нормалей без изменения формы, PBR-материалы и студийный свет. Материалы — художественная визуализация концепта; фактические материалы и отделка изделия не подтверждены.
- `assets/roller-motion.js` — плавное управление ракурсом и стабильный масштаб камеры.
- `assets/roller-print-scene.js` — 3D-коробка, текстура оттиска, камеры и физическое положение колеса.
- `assets/roller-print-motion.js` — стадии прокатки и связь перемещения с углом вращения.
- `assets/customizer-interactions.js` — жесты и анимация нанесения в конструкторе.
- `assets/preview-offer.js` — однократное приглашение в конструктор.
- `assets/request-validation.js` — локальная проверка полей заявки.
- `assets/models/roller.glb` — сборка из архива пользователя.
- `assets/models/roller-geometry.json` — исходные метаданные геометрии.
- `AGENTS.md` — правила и задача для Codex.
- `PROJECT_BRIEF.md` — сценарий и техническая спецификация.
- `scripts/build.mjs` — сборка в `dist/` без зависимостей.
- `tests/request-validation.test.mjs` — проверки имени и контакта (`node --test tests/request-validation.test.mjs`).

## Как развивать в Codex

Откройте эту папку как проект в Codex и попросите: «Продолжи реализацию по AGENTS.md и PROJECT_BRIEF.md». В документах сохранены цели сайта, UX, ограничения и roadmap. Можно перевести проект в React/Next.js, сохранив работающие механики и визуальный стиль.
