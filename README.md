# ROLLÉ — интерактивный 3D-сайт для роллера брендирования упаковки

Готовый автономный MVP премиального продуктового сайта на русском языке. Реальный 3D-роллер выполнен на **чистом WebGL2**, без скачиваемых библиотек и сторонних CDN. Можно развернуть как статический сайт. Основные секции уже сверстаны.

## Быстрый запуск

```bash
cd rolle-3d-site
python3 -m http.server 5173
```

Откройте http://localhost:5173. Если Python отсутствует, достаточно открыть `index.html` в браузере. Можно также подключить Vite / Next.js в Codex.

## Что работает

- 3D-модель роллера с освещением, вращением мышью/тачем и медленной автоподстройкой.
- Режим «Собранный / По деталям» с анимацией разборки 3D-модели.
- Демо нанесения отпечатка на картон и переключатель пяти цветов.
- Конструктор: текст бренда, PNG/JPEG/SVG логотип, цвет оттиска, 3 вида основы, интервал повторения.
- Скачивание SVG-превью.
- До/после с интерактивным ползунком.
- FAQ, адаптивная навигация, запрос заказа с локальным скачиванием TXT.
- Адаптивность для смартфонов, отсутствие внешней телеметрии, базовая поддержка reduced motion.

## Важно перед коммерческим запуском

Это концепт, не модель изготовленного и проверенного изделия. 3D-модель приблизительная, выполнена процедурно по принципу механизма на пользовательском видео. Требуются CAD/Blender-модель настоящего роллера, его точные размеры, профессиональные рендеры, фото реальных оттисков и тесты совместимости маркеров/клише. Реальные корзина, цена, оплата, CRM, backend, безопасность загрузок и политика персональных данных **не реализованы**. SVG из конструктора является визуальным эскизом, не готовым файлом для изготовления печатного клише.

## Структура

- `index.html` — вся семантическая разметка и тексты.
- `assets/styles.css` — адаптивный дизайн, анимации и CSS-сцены.
- `assets/app.js` — WebGL-модель и взаимодействия.
- `AGENTS.md` — правила и задача для Codex.
- `PROJECT_BRIEF.md` — сценарий и техническая спецификация.
- `scripts/build.mjs` — сборка в `dist/` без зависимостей.

## Как развивать в Codex

Откройте эту папку как проект в Codex и попросите: «Продолжи реализацию по AGENTS.md и PROJECT_BRIEF.md». В документах сохранены цели сайта, UX, ограничения и roadmap. Можно перевести проект в React/Next.js, сохранив работающие механики и визуальный стиль.
